先从 Steam 启动忏悔＋，停在主菜单。所有人使用同一种模式。


有服务器码
每人填入同一个服务器码和自己的五字母 ID，点击“连接游戏”。将生成的个人连接码发给主持人，由主持人添加队友、点击“自动测试”。全员已接管后，进入官方联机房间。


没有服务器码
留空服务器码，填写 ID 并连接游戏。每个人添加所有其他队友的个人连接码，再各自点击“启用直连”。双方都有公网 IPv6 时尝试直连，否则使用 Steam 原生；IPv6 不通时，双方可将连线改为 Steam，再启用直连。最后进入官方联机房间。
