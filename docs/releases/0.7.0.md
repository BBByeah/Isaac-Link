# Isaac-Link 0.7.0

- 原生桌面界面，提供墨绿、深红、黑金和紫色主题。
- Steam 辅助通道组队，支持公共 STUN IPv4 打洞，不必配置自建服务器。
- 每对玩家独立选择游戏线路；协调线路在设置中由房主统一指定。
- 点击连线上的线路框查看延迟并切换；点击玩家节点填写局域网地址。
- 监测卡片突出延迟曲线，悬停联动高亮拓扑中的玩家对。
- 设置中提供模拟成员、连接状态测试和抓包。
- 可选检查更新、签名下载、独立更新器安装及失败回滚。

## 下载和启动

下载 `Isaac-Link-client-v0.7.0.zip`，解压完整目录后运行 `以撒联机助手.exe`。不要只复制 EXE，需保留 `_internal` 和 `updater.exe`。

需要自建服务器时下载 `Isaac-Link-server-v0.7.0.zip`。基础组队不需要服务器。

## 升级说明

0.6.5 没有应用内更新器，首次升级请手动下载。0.7.0 开始支持后续版本的应用内更新，更新完全可选，安装前需断开游戏连接。

新协议不支持与 0.6.x 客户端混组，请全队使用同一版本。`update.json` 是客户端读取的签名清单，无需手动打开。
