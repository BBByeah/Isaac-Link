# Isaac-Link 0.7.2 · 跨版本更新测试

此版本用于验证 0.7.0 直接升级到最新 0.7.2，跳过 0.7.1。联机功能与 0.7.0 保持一致，协议仍为 8，使用相同的签名公钥。

0.7.0 客户端点击“检查更新”后应直接显示 0.7.2；无需先安装 0.7.1。下载并验证签名后，断开游戏连接即可安装并重启。保留用户配置、日志、抓包和旧版本备份。

这是普通更新通道中的测试版本，用于验证现有客户端的 `latest` 更新入口。

## r1 安装修复

修复 Windows 下更新器继承安装目录为工作目录，导致目录被占用、无法替换的问题。r1 客户端包仍为 0.7.2，更新器从独立临时目录启动。

已有 0.7.0／0.7.1 用户：将本页的 `start-isaac-link.cmd` 放到主程序旁边，通过它启动后再检查更新。该启动入口可避免旧版安装目录被占用；主程序无需提前替换。新版 0.7.2 r1 之后可直接启动 EXE 更新。
